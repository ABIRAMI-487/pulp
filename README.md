🥤 Pulp — Real Fruit, Zero Sugar Crash

A modern and responsive fruit beverage e-commerce landing page built with HTML, CSS, and JavaScript.

🔗 Live Link

👉 https://stupendous-twilight-00e4ec.netlify.app/

✨ Features

- 🍓 15+ fruit-inspired flavors
- 🛒 Interactive shopping cart
- 💳 Demo checkout experience
- 📊 Sugar comparison section
- ⭐ Customer reviews
- 🥝 Ingredients section
- 📍 Store location section
- 📧 Newsletter subscription
- 🖼️ Product image preview
- 📱 Fully responsive design
- 🎨 Modern and colorful UI

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Netlify — Deployment

📂 Project Structure

pulp/
│
└── index.html


🚀 How to Run

1. Clone the repository:

git clone <your-repository-link>

2. Open the project folder.

3. Open "winning.html" in any modern web browser.

Or use VS Code Live Server to run the project locally.

🛒 Shopping Experience

Users can:

- Browse different flavors
- View product details
- Add products to the cart
- Adjust quantities
- View the cart total
- Proceed through a demo checkout

«⚠️ The checkout functionality is a frontend demo and does not process real payments.»

🎨 Design

The website uses a vibrant fruit-inspired design with:

- Responsive layouts
- Product cards
- Smooth interactions
- Modern typography
- Colorful beverage visuals
- Mobile-friendly navigation

📍 Project Purpose

The project demonstrates how a modern frontend e-commerce beverage website can be designed with interactive product browsing and shopping-cart functionality using basic web technologies.
